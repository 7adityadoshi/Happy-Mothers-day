# Happy-Mothers-day

Interactive single-page Mother&apos;s Day celebration built with React, HTML5 Canvas, and Tailwind CSS.

## Setup

```bash
npm install
npm run dev
```

## Required media in `/public`

- `1.jpeg` (avatar for all games)
- `2.jpeg` to `9.jpeg` (carousel images)
- `10.mp3` (landing background track)
